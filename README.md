## what do i do.
* control the player with wasd and mouse
* turn based combat with dialog
* epic candy sprites and 3d models
* super duper cool world to look around

## why i made this
i decided to make this game because i really wanted to click that 3d editor tab because everytime i was in godot making other games i would honestly accidently click this tab and be confused at why it looked like i was in a cad software for a second and then realized i was in 3d editor instead of 2d editor. i spent some time learning how models get imported and get textured in godot and continued to learn how godot works. overall 10/10.
